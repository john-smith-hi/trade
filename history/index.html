Nạp CSV

Thả file CSV vào đây

Một hoặc nhiều file lịch sử lệnh đã đóng. Trùng ticket thì bản import sau được giữ. Dữ liệu nằm trong trình duyệt này, không ghi vào thư mục web — mỗi lần copy_www.py xóa folder history trên WAMP rồi copy lại code.

Cột bắt buộc: ticket, opening_time_utc, closing_time_utc, type, lots, symbol, opening_price, closing_price, profit. Dùng thêm nếu có: stop_loss, take_profit, commission, swap, close_reason, original_position_size.

Chưa có lệnh

Chọn file CSV hoặc dán JSON orders ở trên. Net = profit + commission + swap. Giờ, thứ và khung trong ngày tính lúc mở lệnh. Ngày, tuần và tháng tính lúc đóng lệnh.
